KIRC Genomic Prognosis

임상정보와 유전자 발현 데이터를 활용한 신장암 환자의 예후 예측

환자의 나이, 암 병기 등 임상정보에 유전자 발현 정보를 추가하면 질병 진행 위험을 더 잘 예측할 수 있는지 분석했습니다.

529명분석 대상 환자
4종생존분석 모델 비교
80/80일괄·개별 추론 결과 일치

직접 수행한 업무

  • 환자별 임상정보와 RNA 발현 데이터를 매칭하고 데이터 품질을 검토했습니다.
  • 학습 데이터에서만 변수 선택 및 전처리 기준을 설정해 평가 데이터의 정보가 학습에 유입되지 않도록 했습니다.
  • 생존분석 모델을 비교하고 환자별 위험도에 기여한 변수와 유전자 발현이 유사한 환자를 확인할 수 있도록 구현했습니다.
  • Streamlit으로 신규 환자 정보 입력과 예측 결과 확인 기능을 구현했습니다.

결과 및 검증

임상정보만 사용한 모델의 평가 C-index는 0.887, RNA를 추가한 모델은 0.892였습니다. C-index는 환자의 위험도 순서를 얼마나 잘 구분하는지 나타내는 지표입니다. 차이의 95% 신뢰구간이 0을 포함해 RNA 추가에 따른 성능 개선이 명확하다고 결론 내리지 않았습니다.

상세 분석 방법과 한계

TCGA-KIRC 환자의 질병 진행까지의 기간(Progression-Free Interval, PFI)을 분석 대상으로 삼았습니다. 정규화된 Cox 회귀 모델(CoxNet)로 임상정보, RNA, 임상+RNA, 임상+경로 수준 유전자 발현 정보의 네 가지 조합을 비교했습니다.

입력 데이터평가 C-index
RNA0.715
임상정보0.887
임상정보 + RNA0.892
임상정보 + Hallmark 경로0.886

환자별 변수 기여도는 Cox 회귀계수와 변환된 입력값의 곱으로 계산했습니다. 유전자 발현 유사 환자 탐색과 학습 집단 내 유사성 평가를 추가했으며, 외부 환자 집단에서의 검증은 수행하지 않았습니다. 예측 점수는 절대적인 질병 진행 확률이 아닙니다.

HeartLink

심부전 환자의 30일 재입원 위험 예측 및 퇴원 관리 지원 시스템

퇴원 전 환자의 재입원 위험을 파악하고, 환자별 위험요인과 심부전 진료지침을 활용해 의료진의 퇴원 관리 및 환자 교육을 지원하는 시스템을 개발하고 있습니다.

4,949명팀 분석 대상 환자
8,077건팀 기준 입원 데이터

프로젝트 내 역할

초기에는 팀원들과 프로젝트 기획, 임상데이터 구축 및 머신러닝 실험을 분담했습니다. 11월 9일 이후에는 진료지침 기반 검색 증강 생성(RAG), 대규모 언어 모델(LLM) 및 관리 계획 API 개발을 전담하고 있습니다.

기능별 분담담당 업무
본인진료지침 검색, 관리 계획 및 환자 교육 초안 생성·검증, 관리 계획 API
예측 모델 담당 팀원재입원 예측 모델 개발·평가, SHAP 기반 위험요인 분석, 예측 API
화면·DB 담당 팀원React 사용자 인터페이스, PostgreSQL 데이터베이스 및 API 연동

01. 의료데이터 분석 및 전처리

  • 선행연구 조사, 심부전 환자 선정 기준과 퇴원 후 30일 이내 모든 원인의 비계획 재입원 정의 검토에 참여했습니다.
  • MIMIC-IV 비식별 임상데이터에서 SQL로 혈액검사 11개 항목의 최초·최종값을 추출해 22개 변수를 구성하고, 심부전 관련 7개 약물군의 처방 여부 변수를 구축했습니다.
  • 검사 시간 경계 조건을 개선해 누락된 검사값을 복구하고, 결측률, 중복 행 및 환자·입원 ID의 정합성을 검증했습니다.
  • 퇴원 이후 정보를 제외하는 추출 기준을 검토하고, 비정형 임상 기록과 기존 환자 집단의 연계 가능성을 분석했습니다.

02. 머신러닝 실험 및 평가

  • 동일 환자의 정보가 학습·검증·평가 데이터에 중복 포함되지 않도록 환자 단위 분할 기준을 검토했습니다.
  • 정형데이터 예측 모델인 TabPFN의 앙상블 추정기 수를 변경하고 여러 평가 지표를 비교했습니다. AUROC는 소폭 상승했지만 AUPRC와 Brier Score가 악화되어 기존 설정을 유지하는 방향으로 판단했습니다.
모델 설정 비교 실험 (Validation)
평가 지표기존 n=4변경 n=8
AUROC ↑0.6715380.671853
AUPRC ↑0.4104190.408926
Brier Score ↓0.1740910.174137

AUROC는 재입원 여부를 구분하는 능력, AUPRC는 재입원 환자 식별에 관한 정밀도와 재현율의 관계, Brier Score는 예측 확률과 실제 결과 간 제곱오차를 평가합니다. 초기 개인 실험 결과이며 팀의 최종 모델 성능은 아닙니다.

03. 진료지침 기반 RAG·LLM 개발 — 주 담당

언어 모델이 의료정보를 임의로 생성하는 위험을 줄이기 위해 환자 상태와 관련된 진료지침을 먼저 검색하고, 검색된 근거를 활용하여 관리 계획을 작성하도록 구성했습니다.

진료지침 구조화→임베딩·벡터 검색→관련도 재정렬→LLM 초안 생성→출력 검증
  • 국내외 심부전 진료지침을 검색 가능한 의미 단위로 나누고 문서 출처와 식별 정보를 구성했습니다.
  • 텍스트 임베딩 모델 multilingual-e5-small과 FAISS를 활용해 관련 문서를 검색하고, bge-reranker-v2-m3로 문서 관련도를 재평가하는 리랭킹을 구현했습니다.
  • 검색 결과의 순위를 비교 평가하고 문서 구조와 검색 방법을 개선했습니다.
  • 환자 임상정보, 팀 예측 모델의 위험도 및 주요 위험요인, 검색된 근거를 언어 모델에 전달하도록 입력 구조를 설계했습니다.
  • Ollama 기반 언어 모델을 연동하고 의료진용 관리 계획 초안을 정형화된 JSON 형식으로 생성하며 근거 출처를 연결하도록 구성했습니다.

04. 환자별 교육 초안 및 생성 결과 검증

  • 심부전 교육 자료를 바탕으로 11개 교육 항목과 환자 상태별 적용 조건을 구조화했습니다.
  • 검사 결과, 동반질환 및 확정된 퇴원 지침 등을 반영하는 교육 초안 생성 로직을 개발하고 있습니다.
  • 근거 없는 의료정보, 임의의 약물 용량·치료 변경 지시, 확정되지 않은 검사 일정 등이 생성되지 않도록 출력 조건과 검증 규칙을 설계했습니다.
  • 생성 결과의 필수 항목 및 표현을 검토하고 특정 누락 정보를 자동으로 보완하는 모듈을 개발했습니다.
현재 개발 및 검증 범위

환자 교육용 근거 검색 인덱스를 별도로 고도화하고 있으며, 승인된 청크만 인덱싱하도록 코드를 구성했습니다. 합성 데이터로 인덱스 구축·재로딩 및 검색 동작을 테스트했으나 실제 교육 자료는 승인된 청크가 없어 인덱싱하지 않았습니다.

Epigenomic Analysis of Enhancers

전사인자 결합에 따른 마우스 배아줄기세포의 인핸서 특성 분석

인핸서는 유전자 발현을 조절하는 DNA 영역입니다. 줄기세포의 유전자 발현을 조절하는 전사인자가 어떤 방식으로 결합할 때 인핸서의 활성 특성이 달라지는지 알아보기 위해 여러 종류의 시퀀싱 데이터를 통합 분석했습니다.

14,910개활성 인핸서 식별

직접 수행한 업무

  • NCBI GEO 공개 데이터를 수집하고 Linux에서 시퀀싱 데이터 전처리 및 참조 유전체 정렬을 수행했습니다.
  • 염색질 접근성과 히스톤 변형 데이터를 통합하고 유전자 전사 시작점 인접 영역을 제외해 활성 인핸서를 정의했습니다.
  • 인핸서를 유전체 위치, 활성 신호 및 전사인자 결합 조합에 따라 분류하고 그룹별 신호를 비교했습니다.
  • 기존에 알려진 인핸서 영역과 무작위 대조군을 비교하여 식별 결과의 타당성을 검토하고 히트맵과 평균 신호 그래프로 시각화했습니다.

주요 연구 결과

인접 영역을 연결하고 히스톤 변형 신호 강도로 분류하는 ROSE 알고리즘을 활용해 슈퍼 인핸서(강한 활성 신호를 보이는 인핸서 영역) 374개와 일반 인핸서 10,028개를 구분했습니다. 연결 이후 영역 수이므로 최초 식별 수와 합계가 다릅니다.

슈퍼 인핸서 38.2%
일반 인핸서 4.4%
졸업논문 Figure 3 수치를 기반으로 재구성 (143/374, 443/10,028)

슈퍼 인핸서에서 네 가지 줄기세포 관련 전사인자(OCT4, SOX2, KLF4, NANOG)의 동시 결합 비율이 더 높았습니다. 네 인자가 모두 결합한 인핸서에서는 높은 양방향 RNA 전사 신호가 관찰되었습니다.

활용 데이터, 상세 분석 방법 및 한계
데이터분석 목적
ATAC-seq염색질이 열려 있는 영역 확인
ChIP-seq히스톤 변형 및 전사인자 결합 위치 확인

Trim Galore, Bowtie2(mm10), SAMtools, Sambamba로 데이터를 처리하고 MACS3와 BEDTools로 분석 영역을 정의했습니다. 전사 시작점 ±2 kb를 제외하여 유전자 사이 7,558개, 유전자 내부 7,352개의 활성 인핸서를 식별했습니다.

deepTools와 HOMER로 그룹별 신호를 비교하고 p300 결합 신호 및 PhyloP 진화적 보존성의 무작위 대조군 비교를 수행했습니다. 공개 데이터 기반 연관성 분석으로 직접적인 실험적 인과관계 검증은 수행하지 않았습니다.
