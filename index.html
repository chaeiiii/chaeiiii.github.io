KIRC Genomic Prognosis

임상정보와 유전자 발현 데이터를 활용한 신장암 환자의 예후 예측

환자의 나이, 암 병기 등 임상정보에 유전자 발현 정보를 추가하면 질병 진행 위험을 더 잘 예측할 수 있는지 분석했습니다.

529명분석 대상 환자
4종생존분석 모델 비교
80/80일괄·개별 추론 결과 일치

직접 수행한 업무

  • 환자별 임상정보와 RNA 발현 데이터를 매칭하고 데이터 품질을 검토했습니다.
  • 학습 데이터에서만 변수 선택 및 전처리 기준을 설정해 평가 데이터의 정보가 학습에 유입되지 않도록 했습니다.
  • 생존분석 모델을 비교하고 환자별 위험도에 기여한 변수와 유전자 발현이 유사한 환자를 확인할 수 있도록 구현했습니다.
  • Streamlit으로 신규 환자 정보 입력과 예측 결과 확인 기능을 구현했습니다.

결과 및 검증

임상정보만 사용한 모델의 평가 C-index는 0.887, RNA를 추가한 모델은 0.892였습니다. C-index는 환자의 위험도 순서를 얼마나 잘 구분하는지 나타내는 지표입니다. 차이의 95% 신뢰구간이 0을 포함해 RNA 추가에 따른 성능 개선이 명확하다고 결론 내리지 않았습니다.

상세 분석 방법과 한계

TCGA-KIRC 환자의 질병 진행까지의 기간(Progression-Free Interval, PFI)을 분석 대상으로 삼았습니다. 정규화된 Cox 회귀 모델(CoxNet)로 임상정보, RNA, 임상+RNA, 임상+경로 수준 유전자 발현 정보의 네 가지 조합을 비교했습니다.

입력 데이터평가 C-index
RNA0.715
임상정보0.887
임상정보 + RNA0.892
임상정보 + Hallmark 경로0.886

환자별 변수 기여도는 Cox 회귀계수와 변환된 입력값의 곱으로 계산했습니다. 유전자 발현 유사 환자 탐색과 학습 집단 내 유사성 평가를 추가했으며, 외부 환자 집단에서의 검증은 수행하지 않았습니다. 예측 점수는 절대적인 질병 진행 확률이 아닙니다.

HeartLink

심부전 환자의 재입원 위험 예측 및 퇴원 관리 지원

퇴원 전 환자의 재입원 위험을 파악하고, 의료진이 환자 상태에 맞는 관리 계획과 교육 자료를 검토할 수 있도록 돕는 시스템을 개발하고 있습니다.

4,949명팀 분석 대상 환자
8,077건팀 기준 입원 데이터

개인 담당 업무

  • 공개 임상데이터베이스 MIMIC-IV에서 검사 및 약물 데이터를 추출하고 결측률과 변수 정의를 검토했습니다.
  • 퇴원 이후 정보가 예측에 포함되지 않도록 데이터 추출 조건을 검토했습니다.
  • 심부전 진료지침을 검색 가능한 단위로 구성하고, 환자 정보와 관련된 근거를 검색·재정렬하는 기능을 개발했습니다.
  • 검색된 근거를 바탕으로 대규모 언어 모델(LLM)이 관리 계획을 작성하도록 연동하고, 생성 결과의 근거 적합성과 출력 형식을 검토했습니다.

현재 개발 범위

팀의 예측 모델 개발과 별도로 진료지침 검색 및 생성형 AI 기반 관리 계획을 담당하고 있습니다. 환자별 교육 초안과 검증 규칙을 개발 중이며, 의료진 검토·승인을 전제로 설계합니다.

기술 구성 및 검증 방향

검색 증강 생성(RAG)은 질문이나 환자 정보에 관련된 문서를 찾아 언어 모델에 제공하는 방식입니다. 문서를 청킹하고 임베딩한 뒤 FAISS 벡터 검색 및 리랭킹(관련도에 따른 재정렬)을 거쳐 근거를 제공하도록 구성했습니다.

근거에 없는 약물 용량이나 치료 지시를 생성하지 않도록 출력 조건을 설정했습니다. 최종 검색·생성 성능과 전체 시스템 검증은 진행 중입니다. 교육용 프로토타입이며 실제 임상에서 검증하거나 사용한 시스템은 아닙니다.

Epigenomic Analysis of Enhancers

전사인자 결합에 따른 마우스 배아줄기세포의 인핸서 특성 분석

인핸서는 유전자 발현을 조절하는 DNA 영역입니다. 줄기세포의 유전자 발현을 조절하는 전사인자가 어떤 방식으로 결합할 때 인핸서의 활성 특성이 달라지는지 알아보기 위해 여러 종류의 시퀀싱 데이터를 통합 분석했습니다.

14,910개활성 인핸서 식별

직접 수행한 업무

  • NCBI GEO 공개 데이터를 수집하고 Linux에서 시퀀싱 데이터 전처리 및 참조 유전체 정렬을 수행했습니다.
  • 염색질 접근성과 히스톤 변형 데이터를 통합하고 유전자 전사 시작점 인접 영역을 제외해 활성 인핸서를 정의했습니다.
  • 인핸서를 유전체 위치, 활성 신호 및 전사인자 결합 조합에 따라 분류하고 그룹별 신호를 비교했습니다.
  • 기존에 알려진 인핸서 영역과 무작위 대조군을 비교하여 식별 결과의 타당성을 검토하고 히트맵과 평균 신호 그래프로 시각화했습니다.

주요 연구 결과

인접 영역을 연결하고 히스톤 변형 신호 강도로 분류하는 ROSE 알고리즘을 활용해 슈퍼 인핸서(강한 활성 신호를 보이는 인핸서 영역) 374개와 일반 인핸서 10,028개를 구분했습니다. 연결 이후 영역 수이므로 최초 식별 수와 합계가 다릅니다.

슈퍼 인핸서 38.2%
일반 인핸서 4.4%
졸업논문 Figure 3 수치를 기반으로 재구성 (143/374, 443/10,028)

슈퍼 인핸서에서 네 가지 줄기세포 관련 전사인자(OCT4, SOX2, KLF4, NANOG)의 동시 결합 비율이 더 높았습니다. 네 인자가 모두 결합한 인핸서에서는 높은 양방향 RNA 전사 신호가 관찰되었습니다.

활용 데이터, 상세 분석 방법 및 한계
데이터분석 목적
ATAC-seq염색질이 열려 있는 영역 확인
ChIP-seq히스톤 변형 및 전사인자 결합 위치 확인
GRO-seq새롭게 합성되는 RNA의 전사 신호 분석

Trim Galore, Bowtie2(mm10), SAMtools, Sambamba로 데이터를 처리하고 MACS3와 BEDTools로 분석 영역을 정의했습니다. 전사 시작점 ±2 kb를 제외하여 유전자 사이 7,558개, 유전자 내부 7,352개의 활성 인핸서를 식별했습니다.

deepTools와 HOMER로 그룹별 신호를 비교하고 p300 결합 신호 및 PhyloP 진화적 보존성의 무작위 대조군 비교를 수행했습니다. 공개 데이터 기반 연관성 분석으로 직접적인 실험적 인과관계 검증은 수행하지 않았습니다.

ASMR Recommender

사용자 취향과 반응 데이터를 활용한 개인화 콘텐츠 추천

일반 영상 추천 환경에서 원하는 ASMR 콘텐츠를 찾기 어려웠던 경험을 바탕으로 개인 취향에 집중한 추천 서비스를 기획했습니다.

주요 작업

  • ASMR 콘텐츠 유형과 사용자 선호 정보를 구조화했습니다.
  • 좋아요, 싫어요, 저장, 스킵 등 사용자 행동을 구분해 개인화 추천 흐름을 설계했습니다.
  • 생성형 AI 개발 도구를 활용하여 웹 애플리케이션의 프론트엔드·백엔드 연동 구조를 구현했습니다.

추천 방식 및 개발 상태

콘텐츠의 특성과 사용자 선호를 바탕으로 순위를 정하는 콘텐츠 기반 추천 프로토타입입니다. 머신러닝 추천 모델을 학습한 프로젝트는 아니며, 최종 배포와 릴리스 검증은 완료되지 않았습니다.
